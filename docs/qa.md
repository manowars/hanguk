# QA trên điện thoại (Samsung S24, Chrome)

Làm theo thứ tự. Đánh dấu ✅ khi qua.

## Cài đặt
- [ ] Mở link app trong Chrome. Menu ⋮ → "Add to Home screen" → có icon 한 trên màn hình.
- [ ] Mở từ icon: chạy toàn màn hình, không có thanh địa chỉ.
- [ ] Vào ⚙️ Cài đặt, dán API key, bấm "Lưu cài đặt". Tắt app, mở lại: key vẫn còn (ô hiện ●●●).

## Giọng nói
- [ ] Cài đặt → "🔊 Thử giọng": nghe tiếng Hàn. Nếu im lặng: Cài đặt máy → Quản lý chung → Chuyển văn bản thành giọng nói → Samsung TTS → tải tiếng Hàn.
- [ ] Nói → Nhại câu → bấm mic: Chrome hỏi quyền mic → Cho phép. Nói một câu tiếng Hàn → chữ Hàn hiện ra.

## Từng phần
- [ ] Nghe: "Tạo bài" → có tiêu đề → "▶ Nghe" phát → "🐢 Chậm" chậm hơn → làm 3 câu → "Nộp" → điểm + lời thoại. Chạm một từ gạch chân → popup → "Lưu vào từ vựng" → toast "Đã lưu".
- [ ] Nói / Nhại câu: 6 câu, mỗi câu nghe → nói → thấy chữ đỏ/cam chỗ sai và "Giống: NN%". Hết 6 câu có điểm.
- [ ] Nói / Đóng vai: AI chào và hỏi → trả lời bằng mic → AI đáp và tự đọc → sau 3 lượt có nút "Kết thúc & nhận xét" → thấy nhận xét kính ngữ, 3 câu tốt hơn, điểm.
- [ ] Đọc: "Tạo bài" → bài đọc → chạm từ → lưu → làm 3 câu → điểm → "Xem bản dịch".
- [ ] Viết: "Lấy đề bài" → gõ 80-150 từ → "Chấm bài" → sao, bản sửa, danh sách sửa. Thoát giữa chừng rồi quay lại: bài nháp còn nguyên.
- [ ] Từ vựng: thẻ đã lưu ở Nghe/Đọc hiện ở "Ôn hôm nay" → bấm "Dễ" → thẻ biến mất khỏi hôm nay → tab "Tất cả" thấy hạn ôn là ngày sau.
- [ ] Trang chủ: ô kỹ năng hiện "lần trước NN%" sau khi làm bài.

## Sao lưu
- [ ] Cài đặt → "Xuất JSON" → file tải về. Xóa một thẻ trong Từ vựng → "Nhập JSON" chọn file → thẻ trở lại.

## Offline
- [ ] Bật chế độ máy bay → mở app từ icon: giao diện vẫn lên, Trang chủ và Từ vựng dùng được. Bấm "Tạo bài" → toast báo không có mạng.

## Lỗi
- [ ] Nhập key sai → "Tạo bài" → toast "API key sai hoặc hết hạn."
- [ ] Từ chối quyền mic → bấm mic → toast hướng dẫn bật mic; vẫn có ô gõ chữ để dùng.
